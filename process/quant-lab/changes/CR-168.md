# CR-168 Economic Cost / Slippage / Impact Computable Evidence Producer Foundation

## 变更描述

在 Stage 2 已完成的合同基础上，为 Stage 3 策略生产建立 fixture/static-only 的 C3 Economic Cost / Slippage / Impact computable evidence producer foundation。该能力只接收显式提供的合成或静态成本输入、交易/持仓变化摘要、成本及 impact 假设、单位口径和 lineage/authorization refs，执行输入充分性、数值相符性、单位相符性、授权边界和 canonical identity 校验，生成可审计、确定性、fail-closed 的 typed C3 evidence component。

该组件复用 CR-166 的 neutral strategy evidence envelope，不连接真实数据湖，不执行真实 TCA，不校准真实市场冲击模型，不启动 Stage 3。

## In Scope

1. 复用 CR-166 strategy evidence envelope，把 `economic_cost@reserved` 演进为 1 个正式、版本化的 C3 component；平行 envelope、registry、策略接纳 gate 数量为 0。
2. 冻结 9 个 C3 输入字段族及 required/optional/N/A/authorization 规则：
   1. manifest/run/strategy identity；
   2. gross return 或 pre-cost performance basis；
   3. trade、position change、turnover、notional basis；
   4. commission/fee assumptions；
   5. tax/levy assumptions；
   6. spread/slippage assumptions；
   7. impact/cost model family、静态参数、`cost_underestimation_status`、model assumptions/structured limitations 或 structured N/A；
   8. unit、currency、calendar、price/notional basis；
   9. lineage、provenance、authorization refs。
3. 定义透明、可审计的 fixture/static 计算：成本分项、total cost、gross-to-net reconciliation、slippage/impact approximation、availability/outcome、reason codes、lineage、canonical identity/hash。
4. impact approximation 只使用显式传入的合成或静态参数，不从真实盘口、成交、订单流、ADV 或 provider 数据估计参数。
5. 冻结 C3/C4 最小共享 header；C4 专属 capacity curve、ADV participation、liquidity sizing、alpha decay 字段保持 reserved，C4 calculator 数量为 0。
6. 提供 1 条 C3 compatibility projection 到现有 Gate 4：只提供 `impact_model_family`、`impact_model_ref`、`cost_underestimation_status`、`no_real_tca_claim`；C4 `reserved/not-built/typed_unavailable` 必须翻译为 `adv_participation_ref`、`capacity_dollars_ref`、`liquidity_sizing_refs` absent 且不得输出字段级 `*_na_reason` / `*_n_a_reason` 或通用 `na_reason` / `n_a_reason`。任何 reason 逃逸输入由 projection `BLOCKED/REJECTED`；canonical Gate 4 validator 与 aggregate orchestration 修改数为 0，capacity/aggregate PASS 为 0。
7. 提供 2 个 fixture 族：1 个 daily multifactor synthetic economic-cost fixture；1 个 multi-strategy-type compatibility fixture，覆盖 daily multifactor 与 ML package attach 语义相符性。
8. 形成 CP2 产品范围、CP3 架构边界、后续 Story/LLD/实现/验证所需的可追溯合同。
