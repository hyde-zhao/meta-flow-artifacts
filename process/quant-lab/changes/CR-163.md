# CR-163 Trial Lineage Instrumentation

## 变更描述

## 核心范围与语义

范围内：family lifecycle、自动 trial/attempt/selection instrumentation、search lineage、明确 count semantics、deterministic sealed manifest、CR151/CR154/admission lineage refs 与 availability 集成。

候选核心对象：`ExperimentFamilySpec`、`TrialLineageRecord`、`TrialAttemptRecord`、`TrialSelectionRecord`、`ExperimentFamilyManifest`、`ExperimentFamilyValidationResult`；最终命名由 CP3 冻结。

必须冻结的计数语义：

1. 同一逻辑 trial 的不同 `attempt_id` 重试不增加 `raw_trial_count`。
2. 相同参数、不同 seed 是不同 trial，并用 `replicate_group_id` 关联。
3. 意外重复不得静默去重，必须记录 duplicate relationship。
4. failed/cancelled/excluded 不得从 lineage 删除；excluded 必须有结构化 reason、时间和决策来源。
5. family 未 seal、总账不一致或 refs 悬空时不得 `present`。
6. seal 后不得原地修改；补充必须生成 superseding manifest/version 并保留前版。
7. 本 CR 只输出 `effective_trial_count_status=typed_unavailable` 及空 ref/method，不得把 raw count 冒充 effective count。

## 执行入口覆盖与 Availability

CP1/CP3 必须形成并冻结 `candidate-producing entrypoint inventory`。P0 至少审查：

- `engine/mature_multifactor_research.py` Stage 3 mature research package 流程；
- `BacktestRunSpec` / `ExperimentManifest` 正式构建路径；
- CR151/CR154/admission package lineage consumer 接口；
- ML/event fixture/static adapter 的共用 producer contract 与兼容测试（不得虚构真实 runner）。

Availability 只使用 CR161 四态：sealed+完整+一致+refs 可解析为 `present`；未接入为 `typed_unavailable`；合法不适用为 `not_applicable_with_reason`；计数矛盾、篡改、悬空 trial 或非法排除为 `blocked`。

- walk-forward/OOS fold 生成与计算、TCA/市场冲击/容量/alpha decay。
- 参数优化算法、最佳参数推荐、策略优选。

- 新真实 lake 读取或写入、NAS/provider/credential、simulation/paper/live/broker/trading 运行。
- 新 CR161 gate family。

## CR155 Negative Regression

- 不反推 `family_id`，不根据已有回测文件猜测 trial 数。
- `ExperimentFamilyManifest` 继续 `typed_unavailable`。
- `blocked_admission_failed`、`paper_candidate=false` 保持不变。
- 新 instrumentation 不得把历史缺失证据误提升为 `present`。

## 量化验收标准

- 冻结 entrypoint inventory 中 candidate-producing 入口 instrumentation 覆盖率 = 100%。
- sealed family 的 trial record 归属覆盖率 = 100%。
- attempted/completed/failed/cancelled/excluded 总账差异 = 0。
- 无 reason 的 excluded trial = 0；无 lineage 的 selected trial = 0。
- 悬空 `trial_id`、`run_id`、`result_ref` = 0。
- 相同输入 manifest canonical hash 一致率 = 100%。
- seal 后原地修改检出率 = 100%。
- 缺 instrumentation fixture 的 `typed_unavailable` 命中率 = 100%，不得 PASS。
- 计数矛盾或 manifest 篡改 fixture 的 `blocked` 命中率 = 100%。
- CR155 negative regression 保持 blocked；禁止操作 counters 全部 = 0。
