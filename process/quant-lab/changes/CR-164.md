# CR-164 Multiple Testing / PBO / DSR Computable Evidence Implementation

## 变更描述

将 CR-161 的 `typed_unavailable` 统计证据合同和 CR-163 的完整 experiment-family trial lineage 事实源连接起来，形成可计算、可复跑、可验证的 multiple-testing / backtest-overfitting evidence。候选方法集合包括 FDR/BH、WRC/SPA、PBO/CSCV 与 DSR/deflation；CP2 必须先确认 MVP 方法组合、输入充分性、失败语义和定量验收标准，CP3 再冻结架构与证据 schema。

本 CR 只授权建立正式工作流、增量产品基线、设计、后续经 CP5 批准的本地实现与 fixture/static 验证。当前不授权真实研究批量计算、生产数据存储/NAS/provider/凭据访问、外部框架运行、交易、发布或远端写入。
