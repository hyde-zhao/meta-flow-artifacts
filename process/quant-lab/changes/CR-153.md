# CR-153 Event-Driven Strategy E2E Framework Foundation

## 变更描述

启动 CR153 Event-Driven Strategy E2E Framework Foundation，先完成规则 41 冲突预检、CP0 受理、CP1 增量 UC-60 场景完备检查和 CP2 范围基线门。

CR153 的目标是在既有 `ResearchDatasetSpec` / `BacktestRunSpec` / strategy admission 资产基础上，补齐事件驱动策略的本地/static/fixture first-wave 方法论契约：三时间语义、事件研究方法契约、事件修订 PIT gate、事件检验报告 slot、overlap / clustering / endogeneity slot、Event admission gate，以及 event -> signal -> target/order-intent trace contract。

CR153 已通过 CP2 人工审查、CP3 HLD / ADR 人工审查和 CP4 Story DAG / parallel safety 自动预检。当前进入 CP5 设计证据准备；CP5 未获用户批准前，不得进行源码实现、真实 runtime、真实数据或交易相关工作。

## 用户目标

用户要求按路线 A 继续推进本地研究 / 策略框架补齐，CR152 已以 `READY_WITH_RISK` 闭环后，下一步启动事件驱动策略 E2E foundation。当前优先级不是数据湖生产级闭环，也不是 live event trading、broker、runtime 或真实事件 feed，而是先把事件研究方法论、PIT / available-at 语义和准入门控范围确认清楚。

## 范围

### In Scope

1. CP0 受理 CR153，记录 CR152 closed 基线、规则 41 预检和当前无 active / blocked formal CR。
2. CP1 增量 UC-60 场景完备检查，基于既有 `process/USE-CASES.md`、roadmap、remediation plan 和 E2E review 确认本轮可进入 CP2。
3. CP2 范围基线门，确认 CR153 first wave 和不授权边界。
4. `EventResearchSpec`：事件类型、来源、event_time、available_at、decision_time、revision policy、dedupe policy、event store refs、market refs、decision boundary。
5. 三时间语义：`event_time` / `available_at` / `decision_time` 必填或 `N/A-with-reason`，策略决策只能消费 `available_at <= decision_time` 的事件事实。
6. `EventStudyMethodSpec`：estimation window、event window、normal return model、CAR / BHAR / calendar-time slot。
7. `EventRevisionPITGate`：事件修订、迟到、重复、可用时点和 blocked event claims 的 fail-closed gate。
8. Event CV slot / split audit refs：只预留 walk-forward / OOS / purged-embargo 引用位，完整框架由 CR154 横切治理承接。
9. `universe_pit_audit` slot：只预留 survivorship-free universe / PIT audit refs，完整 gate 由 CR154 backtest trap gate 承接。
10. `EventStudyTestReport` slot：预留 Patell / BMP / generalized sign / rank / bootstrap slots、状态、report refs 和 `n/a-with-reason`。
11. Overlap / clustering slot 与 endogeneity treatment note slot：只定义 contract slot、status、refs 和 `n/a-with-reason`。
12. `EventStrategyAdmissionGate`：新建 Event-specific admission gate，并通过 adapter 复用 CR151 / CR152 四态 status、blocked reasons 和 admission package linkage。
13. event-to-signal / event-to-order trace contract：只定义 event -> signal -> target/order-intent trace，不启动 listener、paper OMS、broker adapter 或真实 order flow。

### Deferred / Later Wave Candidate

1. Patell / BMP / generalized sign / rank / bootstrap 等具体事件检验算法实现。
2. Cluster robust variance、two-way clustering、portfolio calendar-time regression 等完整统计实现。
3. Heckman / PSM / IV / matching 等内生性 / 自选择修正算法。
4. Event-specific walk-forward / OOS / purged-embargo CV framework；默认归入 CR154 横切治理。
5. Survivorship-free universe 完整 gate；默认归入 CR154 backtest trap gate。
6. Market impact / capacity、attribution、reconciliation、regime gate。
7. live event listener、readonly event feed、paper OMS、broker adapter、runtime、QMT、simulation/live/trading。
8. 真实 lake / NAS / provider / credential / catalog / registry / external framework 相关工作。
9. `FU-CR152-001` test taxonomy / provenance hygiene；保持 candidate，不占 CR153 执行锁。
