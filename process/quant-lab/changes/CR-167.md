## 问题与目标

`quant-lab/docs/release/` 中存在 35 份带 CR 编号的 release notes、deploy checklist、rollback、migration 和 feedback 文档。它们被源码仓库 `.gitignore` 排除，但没有迁入配置声明的 `meta-flow-artifacts/process/quant-lab/docs/release/`，因此只存在于单机工作区，换机或清理目录会永久丢失。

本 CR 的目标是把这 35 份文件迁入 artifact 仓库、提交并推送至 GitHub，同时纠正仍把五个不存在的无 CR 公共发布文件声明为源码保留项的路由元数据和 README 说明。
