## 变更描述

为 `atomic-ops list` 命令的输出增加两个字段，以支持 m-analyzer 的语义匹配需求：

**P0: list 输出增加 tags 字段**（~10 行改动）
- `OperationSummary` dataclass 增加 `tags: list[str]` 字段
- `_operation_summary_from_path()` 读 YAML 时映射 tags

**P1: list 增加参数摘要**（~15 行改动）
- `OperationSummary` dataclass 增加 `parameters_summary: list[dict[str, Any]]` 字段
- 参数摘要仅包含 `{name, type, required}`，不包含描述文本（避免输出膨胀）
- 直接放入默认输出，不引入 `--verbose` 开关
