## 变更描述

用户要求关闭不需要的子 agent，并唤醒 `meta-se` 修订 CP3 HLD。修订范围包括：

1. 处理 `meta-dev` 在 `process/reviews/CP3-HLD-meta-dev-implementation-findings.md` 中提出的 3 个 required findings：
   - `F-001`：schema 扩展字段族、版本 / 兼容策略、现有 atom 迁移和字段参考同步范围未冻结。
   - `F-002`：`session_ref` / `state_ref` 的生命周期、生成方、消费方、允许落盘位置、禁止字段、过期判定和 CLI 解析 / 展示策略不明确。
   - `F-003`：敏感信息零落盘与高风险 gate 的最小机器校验入口未固定。
2. 补齐“同时对多个防火墙设备进行配置”的 HLD 设计，明确多设备选择、批次执行契约、失败隔离、并发限制、幂等性和验证汇总边界。
3. 补齐命令 / 原子操作命名规范、参数校验规则和遵循 atomic-ops 规范的说明。
