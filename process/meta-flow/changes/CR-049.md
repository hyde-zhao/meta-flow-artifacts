# CR-049 Archive and retire merged CR-048 auxiliary branches

## 变更描述

Create immutable annotated archive tags for the two merged CR-048 auxiliary branch tips, verify remote tag reachability, then delete only those local and remote auxiliary branch refs while leaving main unchanged.

## 执行与失败路由

1. 再次核验两个远端分支仍分别指向上述提交，且修复提交是 `main` 祖先；任何漂移均阻断。
2. 创建两个 annotated tag；若 tag 已存在但不指向同一对象，阻断且不得覆盖。
3. 推送 tag，并用远端 peeled ref 核验其目标提交。
4. 只有步骤 3 全部通过，才删除两个远端辅助分支。
5. 删除对应本地辅助分支，fetch/prune 后复核远端仅保留 `main`。
6. 若分支删除后需要恢复，只允许从已核验的 archive tag 重新创建同名分支；不得移动 tag 或改写历史。

## 验收标准

- [ ] 两个 annotated archive tag 已推送且 peeled commit 分别等于 `ad3f6f42...`、`d266e056...`。
- [ ] `origin/integration/cr048-single-source-rules` 与 `origin/fix/claude-md-rule-numbering` 均不存在。
- [ ] 本地 `integration/cr048-single-source-rules` 不存在；本地 fix 分支不存在或原本就不存在。
- [ ] `origin/main` 与本地 `main` 均仍为 `ad3f6f42...`。
- [ ] `d266e056...` 仍是 `main` 祖先，两个历史提交均可由 archive tag 到达。
- [ ] 源码工作树 clean；artifact 只提交 `process/meta-flow/**`，不纳入 `process/quant-lab/**`。
