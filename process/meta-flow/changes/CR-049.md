## 执行与失败路由

1. 再次核验两个远端分支仍分别指向上述提交，且修复提交是 `main` 祖先；任何漂移均阻断。
2. 创建两个 annotated tag；若 tag 已存在但不指向同一对象，阻断且不得覆盖。
3. 推送 tag，并用远端 peeled ref 核验其目标提交。
4. 只有步骤 3 全部通过，才删除两个远端辅助分支。
5. 删除对应本地辅助分支，fetch/prune 后复核远端仅保留 `main`。
6. 若分支删除后需要恢复，只允许从已核验的 archive tag 重新创建同名分支；不得移动 tag 或改写历史。
