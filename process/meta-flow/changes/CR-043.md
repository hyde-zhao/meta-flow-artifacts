# CR-043 Real lake validation task wrapper

## Change Description

CR-043 implements P2-7 from the streamlined roadmap: standardize the evidence package around real-lake-readonly validation tasks without hardcoding quant-lab's private research command.

## Scope

In scope:

- Add `meta-flow validation run`.
- Add the `real-lake-readonly` profile.
- Default to planning and evidence skeleton generation, not command execution.
- Require explicit `--execute` plus `--command` for command execution.
- Generate a validation run ledger, evidence index, rerun comparison, forbidden operation summary and admission summary.
- Publish a latest evidence index at `process/evidence/<CR>.<profile>.validation.index.json`.
- Add tests for dry-run evidence, execute command requirement, consistent reruns and forbidden-op detection.

Out of scope:

- Running quant-lab real lake validation in this repository.
- Reading credentials or private lake/NAS/provider configuration.
- Defining project-specific research command arguments.
- Treating dry-run/planned evidence as satisfying CP7 real validation.
- P2-2 Story management consolidation.

## Acceptance

- `meta-flow validation run --cr CR-155 --profile real-lake-readonly --reruns 2` writes structured planned evidence and exits successfully without executing runtime commands.
- `--execute` without `--command` fails.
- `--execute --command <cmd>` records per-run status, stdout/stderr hashes and rerun consistency.
- `--ops-counter <json>` produces forbidden operation summaries and fails if forbidden operation counts are non-zero.
- The wrapper emits latest evidence at `process/evidence/<CR>.real-lake-readonly.validation.index.json`.

## Not Authorized

- Credential, secret, account, cookie, private-key or token reads.
- Runtime, SaaS, production, data publish, provider publish, lake write, live-trading or trading writes unless a future target CR explicitly authorizes its own command execution.
- Repository push / remote publication execution.
- Writes to `process/quant-lab/**`.

## Closeout

CR-043 closed as `READY_WITH_RISK` on 2026-07-04. It implements `meta-flow validation run` with a `real-lake-readonly` profile, structured run ledger, evidence index, rerun comparison, admission summary and forbidden operation summary outputs.

Remaining risks: target projects still own their concrete validation command contract, and planned dry-run evidence must not be treated as CP7 real validation evidence. These are accepted because the wrapper standardizes evidence generation while preserving explicit runtime authorization.
