# CR-038 State v2 slimming and CR155 gate hardening cleanup

## Change Description

CR-038 implements the Meta Flow-side remediation for legacy runtime state growth and, by approved scope expansion, the CR155 postmortem gate hardening work:

- define a complete ownership map for legacy `STATE.current.json` fields;
- add a tool-supported `meta-flow state slim` path that archives long legacy fields and keeps current state below the v2 budget;
- keep `process/STATE.md` as a short generated human summary and optionally render deny-default history;
- update Codex and Claude Code-facing rules so removed `STATE.md.*` machine fields are no longer treated as live state;
- verify the migration with production-shaped legacy state fixtures.
- block scope/authz contradictions during CR intake;
- pass structured CP2 required evidence into CP7 promise/evidence alignment;
- prevent missing required evidence from being accepted as `PASS_WITH_RISK`;
- distinguish missing execution from executed negative results;
- enforce capsule zone control and capsule/checkpoint content dedup warnings;
- add `standard-lite` as explicit opt-in and wire Batch LLD through lld-designer, CP5, state-router, story-manager, delivery rules and guardrails.

## Scope Expansion Record

The original CR-038 scope was "state v2 slimming and dual-platform rule cleanup". During execution, the user approved the CR155 postmortem implementation results and requested continuation after resolving the remaining blocker: P1-2 Batch LLD skill/template adaptation.

Because the implementation was already completed and verified in the same active CR worktree, this CR records the real expanded scope instead of creating a post-implementation CR. This avoids a false audit chain where a later CR appears to gate code that had already shipped.

Expanded implementation surfaces:

- `meta_flow/checks/cp_result.py`: CP2 required evidence schema, CP7 promise/evidence alignment, status taxonomy and derived consistency checking.
- `meta_flow/context_pack/builder.py`: CP2-to-CP7 `must_verify` injection and capsule content dedup warnings.
- `meta_flow/policies/authz.py`: authz/capability normalization and text inference support.
- `meta_flow/policies/gate_profiles.py`: explicit `standard-lite` profile and `allows_batch_lld`.
- `meta_flow/workflow/cr_lifecycle.py`: L1/L2/L3 scope/authz consistency findings and CR frontmatter ingestion.
- `delivery/skills/lld-designer/templates/BATCH-LLD-TEMPLATE.md`: Batch LLD evidence container for `standard-lite`.
- `delivery/skills/*`, `delivery/agents/*`, `delivery/rules/*`, `README.md`, `delivery/doc/USER-MANUAL.md`: delivery contract updates for hard gates, compact context and Batch LLD.
- `scripts/check_delivery_guardrails.py`: guardrail coverage for Batch LLD contract drift.

Scope expansion does not authorize credentials, runtime execution, production writes, publish, live/trading activity, or writes to `process/quant-lab/**`.
