# CR-038 Codex 子 Agent GPT-5.6 模型路由

## 变更描述

将 Meta Flow Codex 子 Agent 从“未指定模型、继承宿主全局 `model`”改为在安装器内显式路由。默认角色使用 `gpt-5.6-terra`；`meta-dev-debugger`、`meta-se-critical` 与 `meta-qa-critical` 使用 `gpt-5.6-sol`；`meta-doc` 使用 `gpt-5.6-luna`。

canonical Agent Markdown 同时是 Claude Code 和 Qoder 的输入，不在其 front matter 写入 OpenAI 模型名。模型路由只在 Codex 安装分支生效。
