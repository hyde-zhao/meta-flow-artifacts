# CR-037 Project governance and impact surface migration

## Change Description

CR-037 is the umbrella governance change for making Meta Flow project governance records more explicit, compact, and auditable. The currently recovered implementation evidence covers:

- project current-state governance scaffolding and refs-only state separation;
- S07 feature/capability registry resolver support;
- S08 structured impact surface split fields and resolver-backed migration report;
- S09 uncategorized legacy impact reporting and candidate-only follow-up recommendations.
- S10 formal CR-037 governance record.
- S11 configurable legacy impact classification rules.

This formal CR record was created during S10 so later sessions can route CR037 work through normal CR lifecycle checks instead of relying only on scattered story evidence.
