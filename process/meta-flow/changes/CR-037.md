# CR-037 meta-flow project governance and state enforcement remediation

## 变更描述

本 CR 承接 2026-07-02 多轮评审已通过的整改方案，把 meta-flow 当前缺失或失效的项目长期治理能力纳入正式实施跟踪。目标不是新建第二套机制，而是在现有 capsule-first、read-expansion ledger、handoff、gate profile、CR index、capability governance 和 CP result 体系上补齐缺口。

| 字段 | 内容 |

| 目标包 | `GOAL-CR037-project-governance-state-enforcement` |

| P2 | quant-lab state 清理、capability 数据归一、impact_surface migration、roadmap stale report | 不自动修改 quant-lab 发布库代码或正式文档 |

## 验收边界

CR-037 只有在以下条件满足后才能进入 delivered：

- P0 state enforcement 能阻止未知字段和字段预算超限。
- 内部直接写 `STATE.current.json` 的路径已收敛到受控 API。
- `process/project` 能被 bootstrap / workspace check 覆盖。
- `PROJECT.current.json` 自身有 allowlist 和 size budget。
- `impact_surface`、`affected_paths`、`feature_refs`、`capability_refs` 语义分离并有迁移策略。
- `capability_refs` 引用标准 registry 中真实 ID。
- `ROADMAP-REFRESH` 独立 result/checker 可校验。
- quant-lab 迁移只修改过程归档库机器状态，对发布库只输出影响清单和 FU-RF。
