# CR-039 CP8 fact diff and compact release docs

## Change Description

CR-039 implements the first follow-up from CR-038: CP8 must show a compact, machine-readable fact diff between promised scope/evidence and delivered evidence, and release docs must use compact references instead of copying full upstream evidence.

## Scope

In scope:

- Add CP8 fact diff support to CP result validation / rendering.
- Define fact diff fields for promise, delivered evidence, status, risk and CP8 decision impact.
- Ensure missing required evidence cannot silently produce `READY`.
- Allow executed negative results or explicit deferred follow-ups to produce `READY_WITH_RISK`.
- Update release-readiness skill and release templates so compact docs reference `RELEASE-CONTEXT`, `fact_diff` and evidence indexes instead of duplicating evidence bodies.
- Add guardrail coverage for compact release docs and fact diff contract.
- Add regression tests for CP8 fact diff validation and compact release docs contract.

Out of scope:

- P1-0 governance dependency warning.
- P2-5 checker provenance.
- P2-6 publication authz classification.
- P2-1 CP1 grading.
- P2-4 archive / backups isolation.
- P2-7 real lake validation task wrapper.
- P2-2 Story management consolidation.

## Acceptance

- CP8 result can include `fact_diff[]` with promised / delivered / status / risk / decision impact.
- CP8 `READY` / `PASS` is rejected when required evidence is missing.
- CP8 `READY_WITH_RISK` is allowed for executed negative evidence or explicit deferred follow-up risk.
- Release context template includes `fact_diff`.
- Release docs templates reference fact diff / release context / evidence indexes and do not become independent machine truth sources.
- Delivery guardrail checks the fact diff and compact release docs contract.
- Regression suite, guardrail, CR check, CP result checks and `git diff --check` pass.

## Not Authorized

- Credential, secret, account, cookie, private-key or token reads.
- Runtime, SaaS, production, publish, live-trading or trading writes.
- Writes to `process/quant-lab/**`.

## Closeout

CR-039 closed as `READY_WITH_RISK` on 2026-07-04. The implementation delivered CP8 `fact_diff` validation/rendering, compact release context fields, release docs template references, guardrail coverage and regression tests.

Remaining risk: historical CRs without structured CP2 commitments may still need manual `fact_diff` population. This is documented as non-blocking because CR-039 provides the schema, renderer and guardrail contract needed for new CP8 flows.
