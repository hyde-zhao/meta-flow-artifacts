# CR-056 ptm-te 执行场景化：mark 生命周期选例 + 用例库 git 关联 ptm-cases + tde/te 目录树

## 变更描述

用户指令为 ptm-te 增加不同执行场景（本地 / 自动化工厂 / CICD），不同场景通过 `mark` 选取用例；同时将 ptm-te 工作目录 `ptm-te-manaul/cases` 关联远端 `git@10.113.53.21:tgfw/tgfw-ptm/ptm-cases.git`（初始化时检查 GitLab 连通性，连通则自动完成配置），目录树区分 `tde`（设计源）与 `te`（可执行用例），ptm-te 生成的用例一律落 `te/`。
