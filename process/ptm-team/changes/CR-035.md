# CR-035 ptm-te TG 端口生命周期 config-once 实现

## 变更描述

CR-033 引入 case-execution skill（case_runner.py 2552 行编排层）与 op_mapper 23 op_id 全覆盖，CR-034 完成规范文档完备性整改（不改实现）。CR-034 CP8 明确"tg_config_interface 聚合占位符实现（FU-02）属实现 CR 范畴""case_runner/op_mapper 行为变更属实现 CR 范畴"。

本 CR 是 CR-034 的实现 follow-up，**新增 TG 端口生命周期 config-once 编排逻辑**：run 级 acquire-ports（一次）-> tg_config_interface config-once（首个执行后续 skip）-> tg_* op 复用 user_id -> release-ports（run 结束一次）。完全类比已实现的 login-once（fw_login 复用 SHARED_SESSION，Gotcha#8）与 preconfigure_dut_interfaces（已 run 级一次）。

**实现层改动**：op_mapper 注册 acquire/release/verify-ownership op + tg 族 user_id 参数映射；case_runner main 嵌入 run 级 acquire/release + 维护 `tg_interface_configured` 标志 + execute_steps tg_config_interface config-once skip。

## 需求（用户 4 点约束）

### TG 生命周期约束（run 级，跨用例复用）

1. **占用**：每次执行任务（run）时占用 TG 端口（acquire-ports，run 级一次）。
2. **config-once**：TG 端口 IP（tg_config_interface）+ DUT 接口 IP（preconfigure_dut_interfaces）**仅执行一次**，首个 TG 用例真实配置，后续用例复用不重复配置。
   - 后续用例的 tg_config_interface step 标记 skipped（类比 fw_login 复用 SHARED_SESSION，Gotcha#8）。
   - **例外**：若用例特别描述要修改 TG IP，该用例真实执行；**否则不修改 TG 的 IP 地址**。
   - DUT 接口 IP 预配置（preconfigure_dut_interfaces）已 run 级一次，本 CR 不改。
3. **释放**：执行完成后释放占用端口（release-ports，run 结束一次）。
4. **run 级标志**：case_runner 维护 `tg_interface_configured`/`dut_interface_preconfigured`（后者已隐式满足），首次置 True 后续 skip。

### 关键类比

```
DUT 侧（已实现）：login-once（复用 SHARED_SESSION，fw_login step skip）-> fw_* op -> fw_logout
TG 侧（待实现）：acquire-ports -> config-once（tg_config_interface 首次执行后续 skip）-> tg_* op 复用 user-id -> release-ports
```

17 个 TG 用例批量执行时：TG 端口只占用/释放一次、TG/DUT 接口 IP 只配置一次（首个用例），后续用例 tg_config_interface step 自动 skip（除非显式改 IP），避免重复配置 IP 干扰。
