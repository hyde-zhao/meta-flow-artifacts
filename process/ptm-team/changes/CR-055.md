# CR-055 安装器单副本化（废弃 script/install.py）

## 变更描述

cr018 gate4/gate5 预存失败排查（2026-09-02）牵出安装器双副本问题：`script/install.py` 与 `script/ptm_team/install.py` 为同根（ee45ea9）分叉的两份独立实现，各自演进后互缺对方能力/修复：

| 差异 | script/install.py（旧副本） | script/ptm_team/install.py（规范版，CLI/文档实际入口） |
|---|---|---|
| manifest 落盘 | `replace_manifest_entries`（按 key 替换） | `extend`（追加）→ reinstall/重复 install 旧条目残留 → check INSTALLED_DRIFT 假阳性 |
| installed_hash | 源目录全量（含 tests/） | 同（→ 含 tests/ 的 skill 恒定漂移，checkpoint-manager） |
| 规则正文 | 7 条（滞后） | 12 条（最新） |
| S8 模板能力 | ensure_target_project_templates / gitignore / P1 校验 | 缺失 |

用户决策（2026-09-02 结构化）：实施方案 A——**废弃 script/install.py 单副本化**，能力并入规范版后删除旧副本。

实施（均先修根因再删）：
1. **installed_hash 口径修复**（两副本共有漂移根因）：安装后对**目标目录**计算（复制排除 tests/__pycache__/*.pyc，与 check `current_installed_hash` 同口径）；dry-run 目标未写用源兜底。
2. **能力并入**（script/install.py → script/ptm_team/install.py）：`manifest_entry_key` + `replace_manifest_entries`（manifest 3 处 extend → replace）；S8 模板链 `_MODEL_FEATURE_TOKENS` / `_assert_p1_template_placeholderized` / `_ensure_gitignore_rule` / `ensure_target_project_templates` + install_agent 挂 ptm-te 模板段。
3. **删除 script/install.py**；全部引用迁移：tests×6（install_mapping/install_templates/reinstall/cr018/topo_plan_cr037）加载点指规范版、双跑（_both_modules/INSTALLS）单化；文档命令路径（README.md/docs/ptm-tde/README.md/script/README.md/install.py docstring）。
4. cr018 测试资源断言适配规范版模型（component-resource-links.yaml 为源侧清单元数据不落盘，check 读源校验——links 引用校验逻辑规范版已具备）。
5. 前置已修（88550c6）：cr018 gate4/gate5 fixture 补 case_title（614c2ee 契约对齐）。
