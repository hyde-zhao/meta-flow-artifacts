# CR-046：sw3 族接入（sw3_sync_pppoe_route，telnet 旁路）【追溯补记档案】

> ⚠️ **追溯补记说明**：本档案由 CR-039（STORY-039-04，DQ-039-03=B）补建。CR-046 在 **ptm-te-manaul 工作区**已完成实现并实测（PPPoE 环回用例，工作区 SKILL.md 修订记录 v1.7），但 canonical **完全零记录**（op_mapper/case_runner grep sw3 零命中，无变更单、无 DEV-LOG）。本档案补齐追溯链；**canonical 代码回源由 CR-039 STORY-039-03（G5）承载，本档案不附代码**。

## 背景

PPPoE 环回组网（`node3_dut1_tg1_sw1_pppoe_link3`）中，DUT2 作为 PPPoE Client 拨号后获得动态 IP，服务区交换机 **SW3**（H3C，10.113.55.179，PPPoE Server）需同步默认路由下一跳指向该动态 client IP，回程流量才能送达 TG。该同步动作无法经 ptm-atomic 原子操作表达（SW3 是 H3C 交换机，非被测防火墙），故走 **telnet 旁路**：op_mapper `execute_op` 对 family=sw3 分派 `_execute_sw3_op`，用 telnetlib 登录 SW3 执行路由同步。

## 变更内容（工作区实现，canonical 回源锚点）

- **op_mapper.py**（工作区行号；canonical 回源由 STORY-039-03 逐块合并）：
  - sw3 族映射表六处：L130-132（OP_ID_TO_SUBCOMMAND `sw3_sync_pppoe_route: ("sw3", "sync-pppoe-route")`）、L502-505（ARGS_TO_FLAGS）、L578-579（REQUIRED_FLAGS）、L831-835 / L1072-1077 / L1080-1081（回滚策略与描述）、L1958-1966（`_execute_sw3_op`：定位 env_topology SW 节点 + 组装 telnet 调用）、L2124 / L2281 / L2326（execute_op family=sw3 分派）、L3137-3144（validate 三表纳入 sw3）；`EXPECTED_OP_COUNT = 45`（L1081 定义处）。
  - `_exec_sw3_telnet`：telnetlib 登录（username + `password_env` 指向的环境变量）+ `_parse_sw3_pppoe_route`：解析 PPPoE client IP（display 命令输出）+ 同步默认路由下一跳。
- **case_runner.py**（工作区 L54 / L925-950 / L2317-2338）：sw3 step 的 dry-run envelope 支持（dry-run 下只构建打印，不真实 telnet）。
- **env-file 契约**：SW 节点字段 `node_type=SW` / `role=pppoe_server` / `host` / `username` / `password_env=SW3_PASSWORD`（凭据走环境变量，禁止明文，ADR-02）。
- **计数**：`EXPECTED_OP_COUNT` 44->45（sw3 族 +1）。
