# CR-051 ptm-tde 门禁候选清单打印 + 复盘整改

## 变更描述

ptm-tde agent/skills 引用链、计数、台账、解析标准化整改

## 需求基线

### 背景

用户提供 ptm-tde agent 实施二层转发特性的完整复盘（四维度：①实施问题 13 项分 5 组、②流程执行核查对照 CLAUDE.md 7 条规则、③交付件不符合交付标准 4 项、④可改进空间 10 条），并提出**硬性新要求**：

> 你在发起人工门禁时，候选的测试因子和候选的原子操作 id 都需要打印出来让用户确认。

本 CR 以复盘 8 条改进 + 候选打印硬性要求为需求基线，分 P0/P1/P2 实施。

### 改进清单（8 条）

| 编号 | 优先级 | 改进点 | 目标 |
|------|--------|--------|------|
| IMP-051-01 | P0 | 人工门禁（GATE-2/GATE-3）发起时，对话内嵌候选测试因子表 + 候选原子操作表全文，逐项附 decision 状态；禁止只给文件路径 | 用户新硬性要求 |
| IMP-051-02 | P0 | checkpoint-manager manual 审查稿模板增加"候选确认专区"（两张表 + decision 列） | 门禁产物证据化 |
| IMP-051-03 | P1 | gate-spec M10/M11 展示口径：文件存在≠已展示；GATE-5 新增检查项（计数加和/编号存在性/PC 行序） | 门控规范闭环 |
| IMP-051-04 | P1 | ref-integrity 编号引用校验工具（编号存在性/范围展开/引用→定义双向链） | 引用链一致性 |
| IMP-051-05 | P1 | 计数单一权威源 + 加和断言（M+F+Q==TP 分布表） | 计数可信 |
| IMP-051-06 | P2 | feature-parser xlsx 结构化解析契约；bug-gap-analyzer 强制落盘逐条台账 | 输入解析与台账标准化 |
| IMP-051-07 | P2 | 引用 ID 化 + 传播一致性校验；候选 op 状态机（proposed→pending-review→confirmed/rejected/modified/deferred） | 跨层引用与状态机 |
| IMP-051-08 | P2 | 5 设计 Skill PC 编号规则：目录序绑定 + 落区检查 + 决策承诺物化检查 | PC 编号与规模约束 |

### 冲突预检（CR-049 并行声明）

- `STATE.current.json.active_change` 指向 CR-049（ptm-te 组网约束，active）。
- CR-049 影响面为 ptm-te agent/skill 组网约束；本 CR 影响面为 ptm-tde agent/skills 门禁与引用链，**无文件重叠、无契约依赖**（对比 CR-049.md 影响面后确认）。
- 结论：两 CR 可并行推进；本 CR 不修改 ptm-te 相关文件，ptm-tde 文件由本 CR 独占写入。
