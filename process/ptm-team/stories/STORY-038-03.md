# STORY-038-03：PPPoE Server 命令族 + 数据源契约

## 目标

- commands.py 新增三厂商（h3c/ruijie/huawei）PPPoE 命令键：`pppoe.enable_server` / `pppoe.ip_pool` / `pppoe.local_user` / `pppoe.virtual_template` / `pppoe.bind_interface`。
- physical_pool SW 节点新增 `pppoe_server` 块 schema（ip_pool_name / ip_pool_subnet / ip_pool_gateway / virtual_template / authentication / local_users[]）。
- `password_cipher` 仅接受 `${ENV_*}` 占位或设备 cipher 密文，拒绝明文（ADR-02 / ADR-CR038-03）。
- 实现 R-F-003 / R-F-004 / R-F-019。

## 依赖

- 无（W1 起点；physical_pool.py 后续由 STORY-038-13 合并 trex_instances，本 Story 为首次写入方）。

## 设计证据引用（占位）

- Feature 设计：`docs/features/cr038-pppoe-config/DESIGN.md`（§2 数据源契约、§3 命令族）。
- LLD 设计证据：`process/stories/STORY-038-03-LLD.md`（meta-dev 产出，本卡片仅留占位）。

## 验收标准

- SCN-038-POS-004（三厂商命令模板差异正确）PASS。
- R-F-019：pppoe_server 数据源读取路径「同源一致」（physical_pool 唯一真相源）。
- 安全校验：`password_cipher` 明文拒绝、`${ENV_*}` 占位 / cipher 密文放行（ADR-02）。

- 输入：`skills/topo-config/src/commands.py`、`skills/topo-config/src/physical_pool.py`、`skills/topo-config/config/physical_pool.yaml`。
- 输出：上述三文件（+ tests/ 单测）。
