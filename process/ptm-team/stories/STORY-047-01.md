### 接口 / 函数设计

`_parse_post_delay(val) -> float`（模块级私有函数，与工作区签名逐字一致）：

- `val is None` -> `0.0`。
- `isinstance(val, (int, float))` -> `float(val)`（纯数字按秒；负数原样透传，见 open_items）。
- 字符串：`str(val).strip().lower()` 后为空串 -> `0.0`；`"500ms"` 后缀 -> `float(s[:-2]) / 1000.0`（0.5 秒）；`"5s"` 后缀 -> `float(s[:-1])`（5.0 秒）；其余按 `float(s)` 解析纯数字字符串。
- 解析异常（`ValueError` / `TypeError`）-> `0.0`（非法串不中断执行，等效无延迟）。

execute_steps 叠加：主循环 `idx < n - 1` 分支睡眠改为 `OP_INTERVAL_SEC + _parse_post_delay(step.get("post_delay")))`；`step.get("post_delay")` 缺省 None -> 0.0，行为与回源前完全一致（无 post_delay 字段用例零感知）。仅 `--execute` 模式生效（该睡眠行本身位于 execute 分支内，dry-run 不经过）；rollback 清理循环不读取 post_delay。

### 异常处理

- `None`（字段缺省）-> `0.0`，叠加行为与现状一致。
- 空串 / 纯空白串 -> `0.0`。
- 非法串（如 `"abc"` / `"5x"`）-> `float()` 抛 `ValueError`，捕获后返回 `0.0`；类型异常（`TypeError`）同路径兜底。
- 负数（含 `"-1"` / `-1`）-> 原样透传（`-1.0`），与工作区实测一致（SGQ-047-04）；当负值绝对值 ≥ `OP_INTERVAL_SEC` 时 sleep 总和为负会触发 `time.sleep` `ValueError`，本 Story 不 clamp，语义收敛记入 BACKLOG deferred（OPI-047-01）。
- 函数本身不抛出（全路径返回 float），不引入新的执行中断点。
